# Teste de Versionamento Utilizando Branches

Este repositório tem como objetivo praticar o uso do Git com branches e Pull Requests.

## Passos para o Exercício

1. Criar uma página estática com CSS  
2. Adicionar a página ao repositório Git  
3. Criar uma nova branch  
4. Realizar alterações na branch  
5. Criar um Pull Request com as alterações  
6. Validar o Pull Request  
7. Mesclar as alterações na branch `main`  

Siga esses passos para treinar o fluxo de trabalho colaborativo com Git!
